# Game

A 2D top-down Java game (Swing/AWT), built as a learning project.

> **Note:** The base of this project follows a Java 2D game development tutorial. It's a work in progress — I'm actively extending it with original features to move beyond the tutorial base.

## Features so far

- Tile-based world with multiple maps
- Player movement, collision, and combat (melee + projectiles)
- Enemies and NPCs with basic AI and A* pathfinding
- Inventory, items, and equipment (weapons, shields, consumables)
- Dialogue, pause/options menus, and a title screen
- Save/config handling

## Controls

| Key | Action |
|---|---|
| W/A/S/D or Arrow Keys | Move |
| Enter | Confirm / Attack |
| Space | Attack |
| F | Fire projectile |
| E | Interact |
| C | Character/inventory screen |
| M | Map |
| X | Toggle minimap |
| P | Pause |
| Esc | Options |

## Running

Open in IntelliJ IDEA (project files included) and run `main.Main`.
